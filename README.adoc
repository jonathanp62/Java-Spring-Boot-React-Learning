= Spring-Boot-React-Learning

A program that supports React learning projects with REST services provided by Spring Boot.

== REST API Endpoints

[options="header"]
|=======================
|Endpoint                                                         |HTTP Method | Payload | HTTP Responses | Description
|/react/learning/api/bank-kyc-form                                | POST       | JSON    | 201 CREATED    | Returns the saved form as JSON
|/react/learning/api/bank-kyc-form                                | GET        | None    | 200 OK         | Returns all saved forms as JSON
|/react/learning/api/bank-kyc-form/ok                             | GET        | None    | 200 OK         | Returns a string: OK
|/react/learning/api/e-commerce/distance/                         | GET        | None    | 200 OK         | Returns all distance documents as JSON
|/react/learning/api/e-commerce/distance/:toZipCode               | GET        | None    | 200 OK         | Returns the distance document for the specified 'to' zip code as JSON
|/react/learning/api/e-commerce/distance/ok                       | GET        | None    | 200 OK         | Returns a string: OK
|/react/learning/api/e-commerce/ok                                | GET        | None    | 200 OK         | Returns a string: OK
|/react/learning/api/e-commerce/order                             | POST       | JSON    | 201 CREATED    | Returns the saved order as JSON
|/react/learning/api/e-commerce/order/:orderId                    | GET        | None    | 200 OK         | Returns the saved order for the specified order ID as JSON
|/react/learning/api/e-commerce/orders                            | GET        | None    | 200 OK         | Returns all saved orders as JSON
|/react/learning/api/e-commerce/sales-tax                         | GET        | None    | 200 OK         | Returns all saved sales tax documents as JSON
|/react/learning/api/e-commerce/sales-tax/                        | POST       | JSON    | 201 CREATED    | Returns the saved sales tax as JSON
|/react/learning/api/e-commerce/sales-tax/                        | PUT        | JSON    | 200 OK         | Returns the updated sales tax as JSON
|/react/learning/api/e-commerce/sales-tax/:stateName              | GET        | None    | 200 OK         | Returns the saved sales tax document for the specified state name as JSON
|/react/learning/api/e-commerce/sales-tax/abbr/:stateAbbreviation | GET        | None    | 200 OK         | Returns the saved sales tax document for the specified state abbreviation as JSON
|/react/learning/api/e-commerce/sales-tax/:stateName              | DELETE     | None    | 204 NO CONTENT | Deletes the sales tax document for the specified state name
|/react/learning/api/e-commerce/sales-tax/abbr/:stateAbbreviation | DELETE     | None    | 204 NO CONTENT | Deletes the sales tax document for the specified state abbreviation
|/react/learning/api/e-commerce/shipping-cost/calculate           | GET        | None    | 200 OK         | Returns the shipping cost as JSON based on toZipCode, subTotal, and items query parameters
|=======================

== Gradle JavaExec Tasks

Add the --no-configuration-cache option to disable the configuration cache when running bootRun and bootJar tasks.

[options="header"]
|=======================
|Task Name              |Application Invocation
|bootJar                |No arguments
|bootRun                |No arguments
|bootRunDev             |No arguments
|bootRunTest            |No arguments
|=======================
