= Spring-Boot-React-Learning

A program that supports React learning projects with REST services provided by Spring Boot.

== REST API Endpoints

[options="header"]
|=======================
|Endpoint           |HTTP Method | Payload | HTTP Responses                | Description
|/react/learning/api/bank-kyc-form/ok | GET        | None    | 200 OK                        | Returns a string: OK
|/react/learning/api/e-commerce/ok    | GET        | None    | 200 OK                        | Returns a string: OK
|=======================

== Gradle JavaExec Tasks

Add the --no-configuration-cache option to disable the configuration cache when running bootRun tasks.

[options="header"]
|=======================
|Task Name              |Application Invocation
|bootRun                |No arguments
|bootRunDev             |No arguments
|bootRunTest            |No arguments
|=======================
